# Hackathon Project: On-Chain Compute Economy for AI Agents

## DATA LOCATION
Create everything in: /home/zeya/Desktop/compute-economy/

## Project Overview
Build a full-stack dApp on Solana where:
1. GPU providers list compute hours (H100, A100, etc.) for rent
2. AI trading agents rent compute to run strategies
3. Investors deposit SOL/USDC into vaults managed by agents
4. Profits are distributed back to investors

## Tech Stack
- Blockchain: Solana devnet
- Smart Contracts: Anchor (Rust)
- Frontend: Next.js 14 + TypeScript + TailwindCSS
- Wallet: Solana Wallet Adapter
- Backend: Next.js API routes
- Database: PostgreSQL (Neon or Supabase) with Prisma

## PHASE 1: Smart Contracts (Anchor)

### Contract 1: ComputeRegistry
Purpose: Track available compute listings and rentals.

Features:
- `initialize_listing(provider: Pubkey, gpu_type: String, price_per_hour: u64, total_hours: u64)`
- `rent_compute(renter: Pubkey, listing_id: u64, hours: u64)`
- `complete_rental(rental_id: u64)`
- `resell_compute(rental_id: u64, price_per_hour: u64, remaining_hours: u64)`

State accounts:
- Listing: provider, gpu_type, price_per_hour, available_hours, total_hours, status
- Rental: renter, listing, hours_rented, hours_used, start_time, status

### Contract 2: AgentVault
Purpose: Manage investor deposits and agent trading.

Features:
- `create_vault(agent_pubkey: Pubkey, management_fee_bps: u16, performance_fee_bps: u16)`
- `deposit(vault_pda: Pubkey, amount: u64)`
- `withdraw(vault_pda: Pubkey, shares: u64)`
- `agent_execute_trade(vault_pda: Pubkey, trade_instruction: Vec<u8>)`
- `distribute_profits(vault_pda: Pubkey)`

State accounts:
- Vault: agent, total_deposits, total_shares, management_fee, performance_fee, pnl_history
- UserPosition: user, shares, deposited_amount, last_update

### Contract 3: FeeDistributor
Purpose: Handle fee distribution to all parties.

Features:
- `distribute_rental_fee(rental_id: u64)` (provider gets 90%, protocol gets 10%)
- `distribute_trading_fee(vault_pda: Pubkey, profit_amount: u64)` (investors get 80%, agent gets 10%, protocol gets 10%, performance fee to agent)

## PHASE 2: Frontend Pages

### Page 1: Dashboard (page.tsx)
- Hero section explaining the platform
- Stats: Total compute hours listed, total SOL deposited, number of active agents
- Latest compute listings (3-5 items)
- Top-performing vaults (by ROI)
- Call-to-action buttons: "Rent Compute", "Invest in Vault", "List Your GPU"

### Page 2: Compute Marketplace (/providers)
Two views:
**Provider View** (connect wallet to see):
- Form to list compute: GPU type (dropdown: H100, A100, RTX4090), price per hour (SOL), total hours available
- List of my active listings (with edit/cancel options)
- My active rentals (compute I've rented out)
- Earnings history

**Renter View** (any wallet):
- Browse available compute with filters (GPU type, price range, availability)
- Rent compute: select hours, confirm transaction
- My active rentals (compute I'm currently using)
- Resell unused compute: option to list remaining hours on marketplace

### Page 3: Agent Vaults (/vaults)
- Create new vault (agent only): set management fee (0-2%), performance fee (5-20%)
- Browse existing vaults: agent name, total deposits, APY estimate (mock for demo), performance chart
- Deposit into vault: amount in SOL/USDC, receive vault shares
- Withdraw from vault: enter shares, receive underlying assets
- Agent dashboard (if user is agent): manage vault, execute trades (simulated for demo), view pending profits

### Page 4: Agent Dashboard (/agents)
- List of demo AI agents with descriptions:
  1. "Momentum Trader" - trades based on 24h price momentum
  2. "Mean Reversion Bot" - trades when prices deviate from moving average
  3. "Arbitrage Hunter" - finds price differences across DEXes (simulated)
- For each agent: vault address, total AUM, performance chart (mock data), fee structure
- Action: "Invest" (opens deposit modal)

### Page 5: Compute Marketplace Resell (/marketplace)
- List of resold compute hours (from agents who finished early)
- Buy remaining compute hours directly
- Show discount compared to original price

## PHASE 3: Backend API (Next.js API Routes)

### API Endpoints:

1. `GET /api/compute/listings` - returns all active compute listings (with pagination)
2. `POST /api/compute/listings` - provider creates new listing (calls smart contract)
3. `GET /api/compute/listings/:id` - get specific listing details
4. `POST /api/compute/rent` - rent compute (calls smart contract)
5. `GET /api/vaults` - returns all vaults with aggregated data (total deposits, performance)
6. `POST /api/vaults` - create new vault (calls smart contract)
7. `POST /api/vaults/deposit` - deposit into vault (calls smart contract)
8. `POST /api/vaults/withdraw` - withdraw from vault (calls smart contract)
9. `GET /api/agents` - returns demo agent configurations
10. `POST /api/agents/execute/:agentId` - demo endpoint to simulate agent trading (updates vault PnL)
